# רדאר מניות – אפליקציה לטלפון

אפליקציה לטלפון שסורקת כל בוקר את השוק האמריקאי ומציגה מניות עם סיכוי גבוה מהממוצע לעלות. הסריקה רצה בחינם בשרתים של GitHub, בלי מחשב דלוק. האפליקציה נפתחת מסמל על מסך הבית, באנדרואיד ובאייפון.

כלי עזר לסינון ולמחקר, לא ייעוץ השקעות.


## מה יש באפליקציה

- היום: המניות שנבחרו בסריקה האחרונה, עם ציון פוטנציאל, ציון סיכון, גרף והסבר בעברית למה כל מניה נבחרה
- מסך מניה: גרף מחיר, כל האותות, סטופ מוצע וגודל פוזיציה, כותרות החדשות וקישורים
- שוק: מצב השוק (ריבית, אינפלציה, אבטלה, VIX), מלחמות ומתיחות והענפים שהן משפיעות עליהם, ונתוני מדינות
- ביצועים: תיק מסחר על נייר, "מה עובד" – אילו אותות באמת הקדימו עליות, ובדיקה לאחור
- חיפוש: ניתוח של כל מניה אמריקאית לפי סימול (למשל ESLT, TEVA, NVDA)
- היסטוריה: כפתור התאריך למעלה מציג סריקות קודמות
- התראה לטלגרם כל בוקר (לא חובה)


## מה המערכת בודקת

- מחיר ומחזור: מומנטום, חוזק מול S&P 500, צבירת מחזורים, קרבה לשיא, התכווצות תנודה
- קניות מנהלים: דיווחי Form 4 מ־SEC, כולל סריקה של כל השוק
- אנליסטים: עדכוני תחזיות רווח, שדרוגים (כל בית השקעות מדורג לפי הדיוק שלו בעבר) ומחיר יעד
- שורט וימי כיסוי, פעילות אופציות חריגה
- חדשות ואירועים צפויים: דוחות, FDA, חוזים, מיזוגים, הנפקות מדללות, תביעות
- חוזים ממשלתיים בארה"ב
- מלחמות ומתיחות (GDELT), מאקרו (FRED), מדינות (IMF והבנק העולמי)
- ניהול סיכונים: סינון מניות פני ומניות לא נזילות, סטופ לפי תנודתיות וגודל פוזיציה
- יומן שבודק כל המלצה אחרי 30 ו־90 יום ומכייל לבד את משקל האותות


## התקנה מהטלפון (פעם אחת, כ־15 דקות)

את המדריך הזה אפשר לפתוח גם בתוך האפליקציה: הגדרות, ואז "מדריך הקמה", עם כפתורי העתקה.

1. פתח חשבון חינמי ב־github.com והתחבר.
2. צור מאגר חדש: כפתור + ואז New repository. בשם כתוב stock-radar, בחר Public, סמן Add a README file ולחץ Create repository.
3. במאגר: Settings ואז Pages. תחת Source בחר GitHub Actions.
4. עדיין ב־Settings: Secrets and variables, Actions, New repository secret. בשם כתוב SEC_EMAIL ובערך את האימייל שלך. זו דרישה של רשות ניירות הערך האמריקאית.
5. חזור לדף הראשי של המאגר: Add file ואז Create new file. בשם הקובץ כתוב בדיוק .github/workflows/radar.yml, הדבק את כל התוכן של הקובץ ci/radar.yml (נמצא גם במדריך שבאפליקציה עם כפתור העתקה) ולחץ Commit changes.
6. Add file ואז Upload files. בחר את קובץ ה־zip של רדאר המניות כמו שהוא, בלי לחלץ אותו, ולחץ Commit changes. זה מפעיל את ההתקנה.
7. חכה כ־5 דקות. בלשונית Actions תופיע ריצה עם וי ירוק. פתח בדפדפן את הכתובת https://שם-המשתמש-שלך.github.io/stock-radar. בהתחלה תופיע הודעה שהסריקה הראשונה רצה, ואחרי כשעה יופיעו המניות מהסריקה האמיתית.
   אם לא הופיעה ריצה, או שהיא נכשלה בשלב deploy: ודא ששלב 3 בוצע, ואז Actions, radar, Run workflow.
8. התקן על מסך הבית. באנדרואיד (Chrome): תפריט ⋮ ואז "התקנת אפליקציה" או "הוספה למסך הבית". באייפון (Safari): כפתור השיתוף ואז "הוסף למסך הבית".

מכאן הכול אוטומטי: כל בוקר, בימים שלישי עד שבת בסביבות 6:40 שעון ישראל (אחרי ימי המסחר בארה"ב), הסריקה רצה והאפליקציה מתעדכנת. GitHub מריץ לפעמים באיחור של עד שעה.


## עדכון לגרסה חדשה

כשמתקבל קובץ zip מעודכן, מעלים אותו בדיוק כמו בהתקנה: בדף הראשי של המאגר לוחצים על שלוש הנקודות ליד הכפתור Code, אחר כך Upload files, בוחרים את קובץ ה-zip ולוחצים Commit changes. הענן מחליף את הקוד לבד ושומר את כל הנתונים, ההיסטוריה ותיק הנייר.


## לא חובה: ניתוח מניות מהטלפון

הסריקה היומית רצה לבד. כדי להפעיל מהאפליקציה ניתוח של מניה חדשה, סריקה או בדיקה לאחור, צריך לתת לה מפתח גישה:

1. ב־GitHub: תמונת הפרופיל, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
2. ב־Repository access בחר Only select repositories ואת stock-radar.
3. ב־Permissions, תחת Repository permissions, תן ל־Actions את ההרשאה Read and write.
4. לחץ Generate token, העתק את המפתח, ובאפליקציה: הגדרות, חיבור לענן, הדבק ולחץ "שמור ובדוק".

המפתח נשמר רק בטלפון שלך, ויש לו הרשאה רק להפעיל הרצות במאגר הזה.


## התראות לטלגרם

1. בטלגרם, פתח שיחה עם ‎@BotFather, שלח ‎/newbot ובחר שם. תקבל טוקן.
2. שלח הודעה כלשהי לבוט החדש.
3. בדפדפן, פתח api.telegram.org/botהטוקן/getUpdates (במקום "הטוקן" הדבק את הטוקן). העתק את המספר שמופיע אחרי "chat":{"id":
4. ב־GitHub הוסף שני Secrets כמו בשלב 4 של ההתקנה: TELEGRAM_BOT_TOKEN ו־TELEGRAM_CHAT_ID.
5. כדי לבדוק: באפליקציה, הגדרות, "שלח הודעת בדיקה" (דורש את מפתח הגישה מהסעיף הקודם).

אפשר גם וואטסאפ דרך השירות החינמי CallMeBot (Secrets בשם CALLMEBOT_PHONE ו־CALLMEBOT_APIKEY), ושני מפתחות לא חובה: FINNHUB_API_KEY לחדשות נוספות, ו־ANTHROPIC_API_KEY לסיכום חדשות בעברית בעזרת Claude (בתשלום לפי שימוש, ומופעל בקובץ config.yaml).


## שינוי הגדרות

כל ההגדרות נמצאות בקובץ config.yaml עם הסברים בעברית: גודל התיק לחישוב פוזיציות, אחוז הסיכון לעסקה, כמה מניות לבחור, מסנני מחיר ונזילות ועוד. אפשר לערוך אותו ישירות באתר של GitHub (לחיצה על הקובץ ואז סמל העיפרון).


## חשוב לדעת

- המאגר חייב להיות Public כדי שהאפליקציה תתארח בחינם. כל מי שיודע את הכתובת יכול לראות את הבחירות של הסריקה. המפתחות שלך (Secrets) נשארים מוסתרים.
- הנתונים מגיעים מ־Yahoo Finance דרך ספרייה לא רשמית. אם יום אחד הסריקה נכשלת, האפליקציה תציג את סיבת הכישלון בראש המסך.
- הבדיקה לאחור כוללת רק מניות שנסחרות היום ובודקת רק אותות מחיר, ולכן היא אופטימית מהמציאות. את שאר האותות היומן מודד קדימה.
- אף מערכת לא יודעת לחזות זינוקים בוודאות. מניות עם פוטנציאל לעלייה חדה יכולות גם לרדת חדה.


## מקורות הנתונים

מחירים, אנליסטים, שורט, אופציות וחדשות – Yahoo Finance · קניות מנהלים – SEC EDGAR · מאקרו – FRED · מלחמות ומתיחות – GDELT · מדינות – IMF והבנק העולמי · חוזים ממשלתיים – USASpending.gov · חדשות נוספות (לא חובה) – Finnhub


## למי שמכיר קוד

    run.py                 נקודת הכניסה (scan, ticker, backtest, test-alert)
    config.yaml            הגדרות
    ci/radar.yml           קובץ ההרצה בענן (נשמר ב-GitHub בנתיב .github/workflows/radar.yml)
    ci/run.sh, ci/save.sh  מה שרץ בענן ושמירת התוצאות
    docs/                  האפליקציה (HTML/CSS/JS, בלי שלב בנייה) והנתונים שלה ב-docs/data
    radar/                 המנוע: מקורות נתונים, אותות, ניקוד, יומן, בדיקה לאחור, ייצוא
    tests/                 בדיקות: python -m unittest discover tests

היומן (היסטוריית ההמלצות, תיק הנייר והמשקלות שנלמדו) נשמר בענף radar-data במאגר. אפשר להריץ הכול גם במחשב:
python run.py scan --demo מריץ דמו בלי אינטרנט.
